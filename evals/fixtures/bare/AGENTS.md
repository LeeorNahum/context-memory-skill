# Trailhead Lamp

A rechargeable camping lamp, from prototype to a first run of 100 units.

This project keeps what it knows (plans, decisions, status) in a `Context/` directory, following the context-memory skill.

## Layout

- `bom.csv` is the bill of materials.
- `quotes/` holds supplier quotes as they arrive.
- `README.md` is the public project page.
