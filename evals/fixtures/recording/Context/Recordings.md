# Recordings

Dana records meetings with Audiote and drops each export in `Context-Inbox/`. The `date` in an export's header is the time Audiote stopped recording, not when it started, and the first line gives the length. Speaker labels are assigned per recording, so Speaker 1 in one export is not the same person as Speaker 1 in another.
